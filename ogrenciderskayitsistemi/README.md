# OgrenciDersKayitSistemi

OOP Student Course Registration System

## Proje Yönetimi (Kanban)

Bu projede geliştirme süreci GitHub Projects kullanılarak Kanban yöntemi ile takip edilmiştir.
Görevler "To Do", "In Progress" ve "Done" sütunları altında planlanmış ve ilerleme bu pano üzerinden izlenmiştir.
